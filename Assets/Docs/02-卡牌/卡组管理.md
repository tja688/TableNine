# 卡组管理

游戏中有两个基础卡组：**[[帮助卡组]]** 和 **[[恶魔卡组]]**。关卡中两者混合形成 **[[战斗卡组]]**。

## 帮助卡组

### 复原规则

帮助卡在关卡中被使用后，仅 **当前关卡内临时移除**，关卡结束后 **完整复原**。若需永久移除帮助卡，会在卡面明确标注"永久移除"字样。帮助卡组不设跨关卡的消耗。

### 节点快照

每节点开始时对帮助卡组做快照保存。节点结束时，已永久移除的卡不恢复，节点内未使用的卡从快照恢复。新增卡牌（选牌/商店购买/掉落）在恢复后加入。

### 卡组上限

同一种帮助卡允许堆叠（如"恢复药水×3"）。同一名称的帮助卡最多持有 **3张**，达到3张后无法再获得同名卡。同名卡也计入卡组上限（如卡组内有"恢复药水×3"，则在第1层还剩下9张帮助卡可加入卡组）。在关卡内靠着遗物/技能效果获得的帮助卡即使卡组到达上限也能加入卡组，但若是关卡结束依然超过卡组上限则强制移除最后加入的帮助卡。

按层扩容：

| 层数  | 上限  |
| :-- | :-- |
| 第1层 | 12张 |
| 第2层 | 18张 |
| 第3层 | 24张 |

达到卡组上限或同名3张上限时，弹出提示窗口告知玩家。

## 恶魔卡组

恶魔卡组按照当前 [[地图节点]] 数自动构成，详见 [[游戏开发项目/九宫牌局/05-职业与层级/层级系统#恶魔卡组构成]]。每个关卡结束后恶魔卡组 **不继承** 到下一关卡，每个关卡的恶魔卡组独立生成。

## 战斗卡组

关卡开始时，从帮助卡组与恶魔卡组中各抽3张卡，然后将两个卡组洗在一起形成战斗卡组，再从中抽2张。详见 [[游戏开发项目/九宫牌局/01-机制规则/发牌机制]]。

当战斗卡组为空时停止抽牌。
