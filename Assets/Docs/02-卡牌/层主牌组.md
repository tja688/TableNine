# 层主牌组

强精英牌组是提供给每层七~九的地图节点使用的牌组，包含普通[[怪物卡]]与一张层主[[怪物卡]]，每个牌组拥有不同的风格，每层游戏开始时随机选择一个层主牌组使用

## 恶魔卡组生成

每个地图节点的恶魔卡组从对应牌组中按 [[游戏开发项目/九宫牌局/05-职业与层级/层级系统#恶魔卡组构成]] 规则随机抽取生成。精英和层主怪物额外加入，不计入常规配额。
