# 玩家技能

[[玩家卡]] 可通过击败 [[精英]] 后出现的 [[导师卡]] 习得的永久 [[游戏开发项目/归档/深入地牢/技能]]。同类技能不可叠加，获得相同技能时取效果更强者或覆盖。详见 [[游戏开发项目/九宫牌局/04-技能/技能系统#词条叠加规则]]。

## 可选技能（导师卡三选一）

### 刺皮
效果：每次被攻击，对攻击者造成等同于攻击者攻击力的 [[伤害]]。

### 硬皮
效果：获得10点血量上限，每次清空关卡时恢复10点 [[血量]]。

### 历战
效果：每次与敌人战斗时，攻击+1，与其他敌人战斗时攻击复原。跨关卡时保留上一敌人的加成，直到与新关卡的新敌人战斗时才复原基础值。复原仅重置历战自身加成，不重置 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|属性提升卡]]、[[游戏开发项目/归档/深入地牢/遗物]] 等其他来源的属性。

### 军械库
效果：每次关卡结束，选择 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|飞刀]]、[[游戏开发项目/九宫牌局/07-数据/帮助卡数据|爆弹]]、[[游戏开发项目/九宫牌局/07-数据/帮助卡数据|破击锤]] 的其中一张加入玩家的牌组。

### 偶数仇恨
效果：与名字带偶数的 [[怪物卡]] 战斗时，造成双倍伤害。

### 塔之子
效果：每次关卡开始时，将一张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|倍增塔]] 放入 [[道具牌格]]。
