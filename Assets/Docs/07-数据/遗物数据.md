# 遗物数据

全遗物属性、效果、品质、定位一览。

## 白色遗物

### 废物利用机（原活着的肉）
- 属性：无
- 效果：使用 [[帮助卡]] 时，玩家恢复2血量
- 品质：白色
- 定位：道具,恢复

### 木盾
- 属性：护甲+1
- 效果：同时拥有木盾、木剑、木甲三件遗物时，木盾护甲额外+2
- 品质：白色
- 定位：护甲

### 木剑
- 属性：攻击+1
- 效果：同时拥有木盾、木剑、木甲三件遗物时，木剑攻击额外+2
- 品质：白色
- 定位：属性

### 木甲
- 属性：血量上限+2
- 效果：同时拥有木盾、木剑、木甲三件遗物时，木甲生命额外+8
- 品质：白色
- 定位：血量

### 幸运硬币
- 属性：无
- 效果：每击败一个 [[精英]] 或 [[层主]]，将一张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|金币卡]] 加入战斗卡组
- 品质：白色
- 定位：经济，战斗

### 飞刀袋
- 属性：无
- 效果：每关卡开始，将两张飞刀加入到玩家的牌组
- 品质：白色
- 定位：道具，直伤

### 药水袋
- 属性：无
- 效果：每关卡开始，将两张恢复药水加入到玩家的牌组
- 品质：白色
- 定位：道具，恢复

### 废物发射器
- 属性：无
- 效果：使用 [[帮助卡]] 时，对随机一张怪物卡造成2点伤害
- 品质：白色
- 定位：道具，直伤

### 废物涂层
- 属性：无
- 效果：使用 [[帮助卡]] 时，获得1点护甲
- 品质：白色
- 定位：道具
### 弹弓
- 属性：无
- 效果：每移除一张 [[怪物卡]] ，对随机一张 [[怪物卡]] 造成4点伤害
- 品质：白色
- 定位：杀怪，直伤

### 打盾刀
- 属性：无
- 效果：每移除一张 [[怪物卡]] ，获得一点护甲
- 品质：白色
- 定位：杀怪，护甲

### 打金刀
- 属性：无
- 效果：每移除一张 [[怪物卡]] ，获得2金币
- 品质：白色
- 定位：杀怪，经济

### 投诚书
- 属性：攻击+1
- 效果：每移除3张 [[怪物卡]] ，将一张黑桃2洗入本关卡战斗卡组
- 品质：白色
- 定位：杀怪，特殊

### 打卡刀
- 属性：攻击+1
- 效果：每移除10张 [[怪物卡]] ，随机洗入一张白色帮助卡进入战斗卡组
- 品质：白色
- 定位：杀怪，道具
### 除甲刀
- 属性：无
- 效果：如果战斗的对象有护甲，则玩家在本次战斗中攻击+3
- 品质：白色
- 定位：属性

### 重盔甲
- 属性：护甲+1
- 效果：每有两点护甲，每关卡开始额外获得一点护甲
- 品质：白色
- 定位：护甲

### 金币盔甲
- 属性：护甲+1
- 效果：当护甲受到伤害时，每10金币抵消1点伤害，金币数不足时，再扣除护甲（对血量造成伤害时不生效）
- 品质：白色
- 定位：护甲，经济

### 泡沫盔甲
- 属性：护甲+1
- 效果：每关卡第一次护甲归零时，下一次玩家受到伤害时，该次伤害变为0（仅免疫单次伤害，对多段伤害只免疫第一段）
- 品质：白色
- 定位：护甲

### 锻造工具
- 属性：无
- 效果：每关卡开始时，随机永久移除一张帮助卡并获得10点护甲
- 品质：白色
- 定位：护甲，道具

### 复合盔甲
- 属性：无
- 效果：每有三点攻击，每关卡开始获得一点护甲
- 品质：白色
- 定位：护甲，属性
### 血魔
- 属性：无
- 效果：每受到10点伤害，获得一点血量上限
- 品质：白色
- 定位：血量，属性

### 身体潜力
- 属性：血量上限+2
- 效果：每受到15点血量伤害，随机洗入一张白色帮助卡进入战斗卡组
- 品质：白色
- 定位：血量，道具

### 肌肉反击
- 属性：血量上限+2
- 效果：每拥有10点血量，战斗时就对怪物卡多造成1点伤害
- 品质：白色
- 定位：血量，直伤

### 金血
- 属性：血量上限+2
- 效果：每损失1点血量，获得等量的金币
- 品质：白色
- 定位：血量，经济

### 血液转换器
- 属性：血量上限+2
- 效果：每关卡开始，将一张血液转换加入到玩家的牌组
- 品质：白色
- 定位：血量，道具

### 交换按钮
- 属性：无
- 效果：每关卡开始，将一张交换卡放入到道具牌格
- 品质：白色
- 定位：位移，道具

### 旋转按钮
- 属性：无
- 效果：每关卡开始，将一张旋转轮放入到道具牌格
- 品质：白色
- 定位：位移，道具

### 转速引擎
- 属性：护甲+1
- 效果：每次旋转时，多旋转一次
- 品质：白色
- 定位：位移，道具

### 陷阱格
- 属性：无
- 效果：当怪物卡移动到格1时，对该怪物卡造成4点伤害
- 品质：白色
- 定位：位移，直伤

### 旋转技巧
- 属性：无

- 品质：白色
- 定位：位移，直伤

## 蓝色遗物

### 铁盾
- 属性：护甲+2
- 效果：受到的所有伤害减少1点
- 品质：蓝色
- 定位：护甲，特殊

### 锻造器具
- 属性：护甲+2

- 定位：护甲，成长

- 定位：杀怪，属性

### 锐利长剑

- 定位：杀怪，属性

### 活力护符

### 废物剑
- 属性：攻击+2

## 金色遗物

### 金剑
- 属性：攻击+8
- 效果：每进行一次战斗，本遗物提供的攻击-1（最低为0），每移除1张 [[怪物卡]] 本遗物提供的攻击+1
- 品质：金色
- 定位：杀怪，属性

### 龙鳞甲
- 属性：护甲+1，血量上限+6
- 效果：所有 [[怪物卡]] 的攻击-1
- 品质：金色
- 定位：纯属性

### 金色宝箱
- 属性：无
- 效果：获取本遗物时，将两张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|金色宝箱卡]] 加入玩家的牌组（仅生效一次）
- 品质：金色
- 定位：经济

### 狂战士斧
- 属性：攻击+1
- 效果：当前血量低于血量上限的50%时，玩家攻击翻倍（恢复到50%以上后复原）
- 品质：金色
- 定位：条件爆发

### 凤凰羽毛
- 属性：血量上限+8
- 效果：受到致命伤害时，恢复50%血量并永久移除本遗物（一次性免死）
- 品质：金色
- 定位：血量，恢复

### 废物老虎机
- 属性：无
- 效果：使用 [[帮助卡]] 时，从以下效果中随机触发一个（按照括号内的概率随机触发）
	1.恢复2点生命（22%）
	2.获得1点护甲（21%）
	3.随机一张怪物卡造成2点伤害（21%）
	4.获得1点血量上限（10%）
	5.玩家护甲+1（5%）
	6.玩家攻击+1（5%）
	7.获得20金币（10%）
	8.随机洗入一张帮助卡进入卡组（5%）
	9.洗入一张蓝色宝箱卡进入卡组（1%）
- 品质：金色
- 定位：道具
### 金属血液
- 属性：无
- 效果：损失血量后获得等量的护甲
- 品质：金色
- 定位：护甲，血量

### 血液冲击波
- 属性：血量上限+4
- 效果：每次关卡开始时，将一张撞击教程放入到道具牌格，当前血量低于血量上限的50%时，再放入一张撞击教程到道具牌格
- 品质：金色
- 定位：血量，道具

### 超越维度
- 属性：攻+1
- 效果：玩家每战斗一次，旋转一次
- 品质：金色
- 定位：位移，特殊

### 渴望
- 属性：血量上限+10
- 效果：所有恢复血量效果翻倍
- 品质：金色
- 定位：恢复，血量

### 金钱就是力量
- 属性：无
- 效果：战斗时，若本次伤害不足以击杀怪物卡，扣除怪物卡剩余血量两倍的金币然后将怪物卡移除（只对等级不为  [[层主]] 的 [[怪物卡]]生效）
- 品质：金色
- 定位：经济，直伤
