# 层级系统

## 整体结构

游戏共 **3层**，每层 **9个地图节点**（即9关），共27关。击败最后一层（第3层）的 [[层主]] 后，游戏通关。

## 地图节点

每个 [[地图节点]] 对应一个 [[关卡]]。节点内是一次完整的战斗流程。

**特殊节点**：
- 第5个节点：固定为 [[精英]] 战斗
- 第9个节点：固定为 [[层主]] 战斗

## 关卡循环流程

1. **确认玩家位置**：确保 [[玩家卡]] 处于格5
2. **发牌环节**：按 [[发牌机制]] 发牌（开局场上共8张卡 + 玩家卡 = 9格全满）
3. **互动环节**：玩家持续与卡牌互动。产生空格子时从 [[战斗卡组]] 抽牌。玩家每互动一次，除格5外的卡牌顺时针移动一格。详见 [[卡牌移动]]
4. **通关判定**：战斗卡组与九宫格上无任何 [[怪物卡]] 时，出现 [[房间卡]] 按钮。详见 [[战斗机制#通关判定]]
5. **帮助卡选择**：从三张 [[帮助卡]] 中选择一张加入 [[帮助卡组]]（可跳过直接 +10 [[金币]]）
6. **前往下一节点**

> 每个关卡结束后 [[恶魔卡组]] 不继承到下一关卡，帮助卡在关卡中使用后被临时移除，关卡结束后完整复原。详见 [[卡组管理]]。

## 恶魔卡组构成

每个节点的恶魔卡组总数 = **9 + X**（X 为当前地图节点数，1~9）。

按各等级的数量范围随机取值，总和必须恰好等于 9+X。优先级从最低等级开始取随机值，最高等级的数量自动调整为剩余值。

| 节点 | 等级1 | 等级2 | 等级3 | 等级4 | 特殊 |
|:-----|:------|:------|:------|:------|:-----|
| 1 | 6~8 | 2~4 | — | — | |
| 2 | 5~7 | 3~5 | — | — | |
| 3 | 2~4 | 3~5 | 2~4 | — | |
| 4 | 1~3 | 3~7 | 3~6 | — | |
| 5 | 1 | 3~5 | 3~5 | 2 | 精英战斗，击败后出现 [[导师卡]] |
| 6 | 0~1 | 2~5 | 3~6 | 1~5 | |
| 7 | — | 1~4 | 3~8 | 3~6 | |
| 8 | — | 1~4 | 3~10 | 3~8 | |
| 9 | — | 1~2 | 3~10 | 3~10 | 层主战斗 |

**精英/层主击杀奖励**：
- [[精英]] 死亡后洗入战斗牌组：1张 [[帮助卡数据|蓝色宝箱卡]]、1张 [[帮助卡数据|金币卡]]、1张 [[帮助卡数据|属性提升卡]]
- [[层主]] 死亡后洗入战斗牌组：1张 [[帮助卡数据|金色宝箱卡]]、2张 [[帮助卡数据|金币卡]]、1张 [[帮助卡数据|属性提升卡]]

## 房间类型

通关后从房间卡中选择。房间类型不影响出怪数量。

| 房间类型 | 说明 |
|:---------|:-----|
| **商店** | 展示6张 [[帮助卡]] 供购买，加入 [[帮助卡组]]。还可以从帮助卡组中删除帮助卡，每删除一张获得10 [[金币]] |
| **金币房** | 加入一张 [[帮助卡数据|金币卡]] 进入战斗牌组 |
| **宝箱房** | 加入一张 [[帮助卡数据|宝箱卡]] 进入战斗牌组 |
| **属性房** | 加入一张 [[帮助卡数据|属性提升卡]] 进入战斗牌组 |

## 花色风格

怪物按照扑克花色设计风格：
- **黑桃**：偏向攻击
- **红桃**：偏向血量
- **方块**：偏向防御
- **梅花**：偏向特异
