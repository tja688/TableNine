# 层级系统

## 整体结构

游戏共 **3层**，每层 **9个地图节点**（即9关），共27关。击败最后一层（第3层）的 [[层主]] 后，游戏通关。

## 地图节点

每个 [[地图节点]] 对应一个 [[关卡]]。节点内是一次完整的战斗流程。

**特殊节点**：
- 第5个节点：固定为 [[精英]] 战斗（固定在恶魔卡组加入一张等级为精英的怪物卡）
- 第9个节点：固定为 [[层主]] 战斗（固定在恶魔卡组加入一张等级为层主的怪物卡）

## 关卡循环流程

1. **确认玩家位置**：确保 [[玩家卡]] 处于格5
2. **发牌环节**：按 [[游戏开发项目/九宫牌局/01-机制规则/发牌机制]] 发牌（开局场上共8张卡 + 玩家卡 = 9格全满）
3. **互动环节**：玩家持续与卡牌互动。产生空格子时从 [[战斗卡组]] 抽牌。玩家每互动一次，除格5外的卡牌顺时针移动一格。详见 [[游戏开发项目/九宫牌局/01-机制规则/卡牌移动]]
4. **通关判定**：战斗卡组与九宫格上无任何 [[怪物卡]] 时，立即弹出帮助卡三选一覆盖层（可跳过直接 +10 [[游戏开发项目/九宫牌局/00-核心概念/金币]]）。详见 [[游戏开发项目/九宫牌局/01-机制规则/战斗机制#通关判定]]
5. **房间卡事件**：帮助卡选择结束后出现两个 [[房间卡]] 按钮，玩家点击其一后触发所选房间卡事件。
6. **前往下一节点**

> 每个关卡结束后 [[恶魔卡组]] 不继承到下一关卡，帮助卡使用后默认永久移除。详见 [[游戏开发项目/九宫牌局/02-卡牌/卡组管理]]。

## 恶魔卡组构成

每个节点的恶魔卡组总数 = **9 + X**（X 为当前地图节点数，1~9）。

**生成规则**：从存在配额的**最低等级**开始逐级随机取值，最高等级数量 = 总数 - 已生成数量（自动填充）。精英/层主怪物**额外加入**，不计入 9+X。

| 节点 | 总数 | 等级1(含无色) | 等级2 | 等级3 | 等级4 | 备注 |
|:-----|:-----|:-------------|:------|:------|:------|:-----|
| 1 | 10 | 7~8 | 2~3(自动) | — | — | |
| 2 | 11 | 6~8 | 3~5(自动) | — | — | |
| 3 | 12 | 3~5 | 3~5 | 2~6(自动) | — | |
| 4 | 13 | 1~3 | 3~5 | 5~9(自动) | — | |
| 5 | 14 | 1(固定) | 3~5 | 3~5 | 3~7(自动) | +1精英(额外) |
| 6 | 15 | 0~1 | 2~4 | 3~5 | 5~10(自动) | |
| 7 | 16 | — | 1~3 | 3~6 | 7~12(自动) | |
| 8 | 17 | — | 1~3 | 3~6 | 8~13(自动) | |
| 9 | 18 | — | 1~2 | 3~5 | 11~14(自动) | +1层主(额外) |

**精英/层主击杀奖励**：
- [[精英]] 死亡后洗入战斗牌组：1张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|蓝色宝箱卡]]、1张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|金币卡]]、1张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|属性提升卡]]
- [[层主]] 死亡后洗入战斗牌组：1张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|金色宝箱卡]]、2张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|金币卡]]、1张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|属性提升卡]]

## 房间类型

通关后从房间卡中选择。选择和触发特定事件

| 房间类型    | 说明                                                                               |
| :------ | :------------------------------------------------------------------------------- |
| **商店**  | 展示6张 [[帮助卡]] 供购买，加入 [[帮助卡组]]。还可以从帮助卡组中删除帮助卡，每删除一张获得10 [[游戏开发项目/九宫牌局/00-核心概念/金币]] |
| **金币房** | 获得50金币                                                                           |
| **宝箱房** | 从三件遗物中选择一件（白色遗物 65%，蓝色遗物 30%，金色遗物 5%）                                            |
| **温泉房** | 提高玩家4点血量上限，并恢复满玩家血量                                                              |


## 花色风格

怪物按照扑克花色设计风格：
- **黑桃**：偏向攻击
- **红桃**：偏向血量
- **方块**：偏向护甲
- **梅花**：偏向特异
