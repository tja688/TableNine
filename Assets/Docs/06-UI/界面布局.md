# 界面布局

![[九宫格战场.png]]

## 区域划分

| 区域 | 位置 | 内容 |
|:-----|:-----|:-----|
| **玩家信息面板** | 屏幕左上方 | 头像、血量（当前/上限）、攻击、防御、状态、[[金币]] 数量 |
| **装备栏** | 屏幕左下方 | 存放已装备 [[遗物]]，上限12件（右键点击可丢弃遗物） |
| **作战场地** | 屏幕正中上方 | [[九宫格战场]]（格1~格9） |
| **道具牌格** | 屏幕正中下方 | 存放已获取的 [[帮助卡]]，上限5格，满时无法拾取新帮助卡 |
| **技能栏** | 屏幕右下方 | 玩家拥有的 [[技能]] 及其描述 |
| **牌组区** | 屏幕右上方 | [[战斗卡组]] 存放处，正面朝上显示下一张会放到空格子上的卡牌 |
| **介绍区** | 屏幕右中间 | 鼠标悬停在 [[怪物卡]] 上时，显示怪物技能详细描述 |

## 显示规则

**玩家面板**：显示的攻防数值为 **有效属性**（基础 + [[遗物]] + [[技能]] + [[套装]] 加成），非裸值，即时结算。详见 [[伤害公式#显示规则]]。

**怪物卡牌**：显示的攻防数值包含技能加成（[[鼓舞]] 光环 + [[复仇]] 累计），实时反映实际战斗数值。

**牌组区下一张预览**：[[战斗卡组]] 有牌时显示牌面信息（怪物：名称/血/攻/防；帮助卡：名称/品质/效果），无牌时显示"牌组已空"。

## 覆盖层系统

[[帮助卡]] 选择、[[商店]]、[[导师卡]]、[[帮助卡数据#宝箱卡|宝箱]] 选择均使用半透明黑色背景覆盖层，阻止下层点击。

## 弹窗系统

购买上限、遗物满格等提示使用居中弹窗，点击任意位置关闭。

## UI 接入工作流

当前工程侧 UI 接入以 `Assets/ScriptableObjects/TableNineUIPanelRegistry.asset` 为集中配置入口。玩法层只发送领域事件或 UI 请求事件，`TableNineUIRouter` 根据稳定 `UIKey` 打开正式 UIKit 面板；正式面板未绑定时，统一回退到 `UIFallbackPanel` 的原子组件表现。

已注册的全部 UI Key 与 Router 接入状态见：`Assets/Notes/UIWorkflow.md`。
