# 战斗机制

## 交互范围

[[玩家卡]] 固定出生在格5，可被效果移动，但没有自行移动手段，仅通过点击九宫格上的卡牌进行交互。

- 点击 [[怪物卡]]：与目标怪物进行战斗（结算伤害）
- 点击 [[帮助卡]]：拾取到 [[道具牌格]]，详见 [[游戏开发项目/九宫牌局/02-卡牌/帮助卡系统]]
- 玩家只能与玩家卡 **正交相邻** 格子上的卡牌进行互动
- 道具牌格使用帮助卡**不受正交相邻距离限制**，可瞄准九宫格任意怪物

## 伤害结算

详细计算公式见 [[游戏开发项目/九宫牌局/01-机制规则/伤害公式]]。

**标准结算流程**：无 [[游戏开发项目/九宫牌局/01-机制规则/先攻]] 时，玩家先对目标造成伤害；若目标未死亡，则目标进行反击造成伤害。拥有先攻的一方优先造成伤害。

**优先级规则**：先攻技能 > 玩家默认优先。

| 情境     | 结算顺序                                                                    |
| :----- | :---------------------------------------------------------------------- |
| 双方均无先攻 | **玩家先** 造成伤害                                                            |
| 双方均有先攻 | **玩家先** 造成伤害                                                            |
| 一方有先攻  | **先攻方** 先造成伤害(怪物先攻时，怪物先造成伤害，玩家后反击；先攻方击杀对方则对方无法反击)                       |
| 伤害致死   | 死亡的一方 **无法造成伤害**；若双方同时受到致命伤害，则双方同时死亡（如果玩家卡互动先造成足以击杀怪物卡的伤害，则这次怪物卡不会造成伤害） |

## 战斗结算详细流程

1. 点击怪物卡 → 检查紧握锁 → 通过则进入战斗
2. 计算有效属性（详见 [[游戏开发项目/九宫牌局/01-机制规则/伤害公式]]）
3. 玩家先手造成伤害（[[游戏开发项目/九宫牌局/01-机制规则/先攻]] 技能确保优先权）
4. [[荆棘甲]] 额外伤害同时生效
5. 怪物血量 ≤ 0 → 击杀结算（[[游戏开发项目/九宫牌局/00-核心概念/金币]]、[[游戏开发项目/归档/深入地牢/遗物]] 效果、[[导师卡]] 触发）
6. 怪物存活 → 怪物反击（计算有效攻击），同时 [[刺皮]] 技能反伤生效（双方伤害同步结算）
7. [[庇佑魔法卡]] 可免疫单次反击伤害
8. [[凤凰羽毛]]：致命伤时恢复50%血量并消耗遗物
9. [[红桃之母]] 技能：累计损失每满10血，洗入红桃到战斗卡组

## 战斗输入锁定

以下任一状态激活时，禁止玩家发起新的战斗互动：
- 战斗结算进行中（compatResolving）
- 棋盘补牌执行中（boardRefillRunning）
- 覆盖层/弹窗显示中（帮助卡选择、商店、导师卡、宝箱选择等）

输入锁定防止战斗动画/补牌过程中的重复点击导致的状态异常。

## 通关判定

当 [[战斗卡组]] 与九宫格上没有任何 [[怪物卡]] 时，立即弹出帮助卡三选一覆盖层。选择结束后出现两个 [[房间卡]] 按钮。玩家可自行选择何时点击房间卡按钮决定下一个房间的类型。

 [[房间卡]] 按钮出现后，玩家仍可：
- 点击九宫格上的帮助卡 → 拾取到 [[道具牌格]]
- 点击道具牌格中的帮助卡 → 正常使用效果
- 无法再与怪物卡战斗（已无怪物）

点击通关按钮后，计算未使用帮助卡 [[游戏开发项目/九宫牌局/00-核心概念/金币]] 奖励，进入所选房间卡，结束房间卡事件后进入下一地图节点。详见 [[游戏开发项目/九宫牌局/05-职业与层级/层级系统#关卡循环流程]]。

## 右键交互

装备栏中已装备的 [[游戏开发项目/归档/深入地牢/遗物]] 支持 **右键点击丢弃**，丢弃后获得20 [[游戏开发项目/九宫牌局/00-核心概念/金币]]。游戏启动时禁用浏览器默认右键菜单。
