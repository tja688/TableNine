# 先攻

## 定义

[[玩家卡]] 或 [[怪物卡]] 拥有的特殊 [[词条]]，决定 [[战斗机制|战斗]] 中谁先造成伤害。

## 优先级

| 情境 | 先手方 |
|:-----|:-------|
| 双方均无先攻 | 玩家先 |
| 双方均有先攻 | 玩家先 |
| 仅一方有先攻 | 先攻方先 |

拥有先攻的一方优先造成伤害。如果先攻方的伤害足以击杀对方，对方无法造成伤害。

## 持有者

- [[梅花幼崽]]（怪物）：梅花2 持有
- [[先攻]]（通用技能）：可被怪物或玩家获得
