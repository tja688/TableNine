# 属性

## 定义

[[玩家卡]] 或 [[怪物卡]] 拥有的基础数值，在战斗中发挥不同作用

## 详细作用

| 属性名称 | 作用                            |
| :--- | :---------------------------- |
| 攻击   | 决定造成伤害的数值                     |
| 防御   | 每个关卡开始和获得防御时提供等同于自身数值的护甲      |
| 血量   | 能承受的伤害总量                      |
| 护甲   | 当受到伤害时，优先扣除护甲，当护甲为0时，伤害才会扣除血量 |
属性最低均为0，不可为负数
获得血量上限时立刻获得等量的血量
