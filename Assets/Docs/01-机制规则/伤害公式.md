# 伤害公式

## 基础公式

玩家对怪物造成的战斗伤害 = 玩家攻击 - 怪物防御
怪物对玩家造成的战斗伤害 = 怪物攻击 - 玩家防御
伤害最低为0，不可为负数。

## 有效属性计算

**玩家攻击** = 基础攻击 + [[遗物]] 加成 + [[套装]] 加成 + [[历战]] 加成 + [[暴力卡]] 翻倍

**玩家防御** = 基础防御 + [[遗物]] 加成 + [[套装]] 加成

**怪物攻击** = 基础攻击 + [[鼓舞]] 光环（其他怪物） + [[复仇]] 累计

## 显示规则

玩家面板和卡牌上显示的攻/防/血为 **有效总值**（基础 + 遗物 + 套装 + 技能），非裸值，即时结算。怪物卡牌显示的攻防数值包含技能加成（鼓舞光环 + 复仇累计），实时反映实际战斗数值。

详见 [[界面布局#显示规则]]。

## 特殊伤害

以下伤害 **无视防御，不可被减免**：
- [[尖盾]]：每次战斗对玩家造成2点
- [[侧方打击]]：移动到角落格时对玩家造成3点
- [[荆棘甲]]：每次战斗对怪物造成2点
- [[瞭望塔]]：在九宫格上对任意怪物造成3点 / 在道具牌格每战斗一次造成2点
