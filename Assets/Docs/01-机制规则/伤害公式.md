# 伤害公式

## 基础公式

玩家对怪物造成的实际伤害 = 玩家攻击 - 伤害减免（技能/遗物效果获得）
怪物对玩家造成的实际伤害 = 怪物攻击 - 伤害减免（技能/遗物效果获得）
标注"无视护甲"的伤害直接扣血量，不扣除护甲。
当受到伤害时，优先扣除护甲，当护甲为0时，伤害才会扣除血量
实际扣血最低为0，不可为负数。


## 有效属性计算

**玩家攻击** = 基础攻击 + [[游戏开发项目/归档/深入地牢/遗物]] 加成 + [[游戏开发项目/九宫牌局/03-遗物/套装]] 加成 + [[历战]] 加成 + [[暴力卡]] 翻倍

**玩家防御** = 基础防御 + [[游戏开发项目/归档/深入地牢/遗物]] 加成 + [[游戏开发项目/九宫牌局/03-遗物/套装]] 加成

**怪物攻击** = 基础攻击 +提升攻击的光环[[游戏开发项目/归档/深入地牢/技能]] + [[复仇]] 累计

## 显示规则

玩家面板和卡牌上显示的攻/防/血为 **有效总值**（基础 + 遗物 + 套装 + 技能），非裸值，即时结算。怪物卡牌显示的攻防数值包含技能加成（光环 + 复仇累计），实时反映实际战斗数值。

详见 [[游戏开发项目/九宫牌局/06-UI/界面布局#显示规则]]。
