# 发牌机制

## 开局发牌

关卡开始时按以下顺序发牌：
1. 从 [[帮助卡组]] 中抽3张卡，随机摆放在空格子上
2. 从 [[恶魔卡组]] 中抽3张卡，随机摆放在空格子上
3. 将帮助卡组与恶魔卡组洗在一起，形成 [[战斗卡组]]
4. 从战斗卡组中抽2张卡，摆放在空格子上

开局场上共8张卡 + [[玩家卡]] = 9格全满。

## 空格补牌

每当九宫格上出现空格子（如怪物被击杀、帮助卡被拾取），自动从 [[战斗卡组]] 抽一张牌打出到空格子上。

**批量补牌**：若同时存在多个空格子，连续抽取直到填满或卡组耗尽，补牌间隔约0.5秒。

**补牌延迟**：击杀怪物后延迟约500ms补牌，拾取帮助卡后延迟约450ms补牌，给玩家视觉缓冲。

**补牌防抖**：短时间内连续多个补牌请求合并为一次批量处理，防止并发吞卡。同一时间段内只执行一次补牌操作。

补牌完成后自动检查通关条件。

## 战斗卡组耗尽

当 [[战斗卡组]] 为空时，停止抽牌。九宫格上可能留有永久空格。
