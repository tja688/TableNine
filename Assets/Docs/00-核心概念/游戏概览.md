# 九宫牌局

> **一句话定义**：在狭小的 [[九宫格战场]] 内展开的肉鸽卡牌冒险。

**核心灵感**：迷失之径，魔塔 × 星陨传说（Meteorfall）

**核心玩法**：利用自身属性与 [[帮助卡]] 牌组里的卡牌消灭掉 [[恶魔卡组]] 里的所有 [[怪物卡]]。

**交互方式**：[[玩家卡]] 固定出生在格5，仅通过点击九宫格上的卡牌进行交互。[[九宫格战场]] 用于控制怪物位置，触发与位置相关的 [[词条]]（如紧握、伏击等）。
