# 九宫牌局

> **一句话定义**：在狭小的 [[游戏开发项目/九宫牌局/01-机制规则/九宫格战场]] 内展开的肉鸽卡牌冒险。

**核心灵感**：迷失之径，魔塔 × 星陨传说（Meteorfall）

**核心玩法**：利用自身属性与牌组（[[通用牌组]] + 职业牌组）里的卡牌消灭掉恶魔卡组生成的所有 [[怪物卡]]。

**交互方式**：[[玩家卡]] 固定出生在格5，仅通过点击九宫格上的卡牌进行交互。[[游戏开发项目/九宫牌局/01-机制规则/九宫格战场]]上的卡牌会不断的旋转 用于控制怪物位置，触发与位置相关的 [[游戏开发项目/归档/深入地牢归档/词条]]。
