### 基线核查结论（重点核查项）

| 项 | 现状 |
|----|------|
| `CalculateDamage` | 仍为 `Attack - Defense`（下限 0） |
| `ApplyDamageCommand` | legacy `int` 重载仍只扣 HP（R1 已加 DamageContext 重载，见 R1 汇报） |
| `UseHelpCardCommand` | 仍大段 `switch(cardId)` |
| `ConsumeHelpCardCommand` | 仍由调用方传 `permanentlyRemove`（R1 已改读取 `RestoreAfterNode`） |

| `EffectSystem` | 空实现 |
| `ISkillSystem` | 未注册 |
| `MemorySaveUtility` | 仍为默认存档 |

- 通关顺序：当前 ClearReady 后直接奖励链 vs Plan R6 房间→奖励→节点结束
